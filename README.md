# TripleTen web_project_expenses

# Gestor de Gastos Personales

Una aplicación web interactiva diseñada para realizar un seguimiento y optimizar las finanzas personales mediante la organización de gastos por categorías, el cálculo de estadísticas en tiempo real y la actualización visual del saldo de la cuenta. Desarrollado como parte del bootcamp de desarrollo web de TripleTen (Sprint 7).

## 🚀 Características

- **Cálculo de saldo en tiempo real:** Actualiza dinámicamente el presupuesto total, los gastos generales y el saldo restante de la cuenta.
- **Indicadores visuales de estado:** Cambia el color del saldo de forma dinámica (`green` / verde, `orange` / naranja o `red` / rojo) según el nivel de gasto para alertar sobre el estado financiero.
- **Desglose de gastos por categoría:** Calcula los totales específicos para categorías clave como comida, comer fuera, transporte, hogar y suscripciones.
- **Métricas inteligentes:** Calcula automáticamente el importe del gasto promedio e identifica con precisión la categoría con el mayor gasto acumulado.
- **Ventanas emergentes interactivas:** Permite interactuar con la interfaz para asignar presupuestos personalizados y agregar nuevos gastos a través de formularios interactivos.

## 💻 Tecnologías Utilizadas

- **JavaScript:** Lógica central del proyecto, bucles, arrays anidados y manipulación de datos en el archivo `calculations.js`.
- **HTML5:** Estructura semántica del documento y enlace correcto de los scripts.
- **CSS3:** Metodología BEM para el diseño visual, hojas de estilo organizadas y adaptables.

## 🧠 Lo que Aprendí en este Proyecto

Durante el desarrollo de esta aplicación, puse a prueba mis conocimientos y dominé:

1. **Implementación de algoritmos de búsqueda:** Creación de un sistema de filtrado de datos y búsqueda de valor máximo para identificar la categoría con mayor gasto (`calculateLargestCategory`).
2. **Reutilización de código (Principio DRY):** Aprendí a aprovechar funciones de utilidad ya creadas dentro de otros bucles para mantener el código limpio, eficiente y sin repeticiones.
3. **Métodos de arrays y estructuras anidadas:** Manipulación avanzada de listas que contienen sublistas y uso de bucles modernos `for...of` para iterar datos eficientemente.
4. **Control de versiones con Git:** Configuración de repositorios locales, enlace de servidores remotos en GitHub y resolución de conflictos de sincronización de manera segura de principio a fin.
